# Onde Eu Parei

Aplicação web para **gerenciamento de estudos baseada em ciclos**, desenvolvida para ajudar estudantes a organizarem sua rotina de preparação para **ENEM e concursos públicos**.

A plataforma permite planejar ciclos de estudo personalizados, acompanhar o progresso nas disciplinas e retomar facilmente os estudos **exatamente de onde o estudante parou**.

---

## Sobre o projeto

O **Onde Eu Parei** foi desenvolvido com o objetivo de tornar mais simples e eficiente a organização dos estudos para provas de grande volume de conteúdo, como **ENEM e concursos**.

Muitos estudantes utilizam o método de **ciclo de estudos**, que consiste em estudar disciplinas em sequência, avançando continuamente no ciclo e retomando o ponto onde pararam na sessão anterior.

A aplicação digitaliza esse processo, permitindo que o estudante:

* organize suas disciplinas
* defina tempos de estudo para cada matéria
* acompanhe o progresso dentro do ciclo
* registre sessões de estudo
* visualize métricas e desempenho ao longo do tempo

---

## Funcionalidades

* criação de **ciclos de estudo personalizados**
* gerenciamento de **disciplinas**
* controle de **progresso dentro do ciclo**
* registro de **sessões de estudo**
* visualização de **métricas de desempenho**
* retomada automática do ponto onde o estudante parou

---

## Interface

A interface foi desenvolvida com foco em:

* **organização visual**
* **usabilidade**
* **clareza das informações**
* **facilidade de navegação entre ciclos e disciplinas**

O objetivo foi criar uma experiência que permita ao estudante entender rapidamente:

* onde está no ciclo
* qual a próxima disciplina
* quanto já estudou

---

## Método de estudo

O sistema utiliza o método de **ciclo de estudos**, bastante adotado por estudantes de **ENEM e concursos públicos**.

Nesse método:

1. o estudante define um conjunto de disciplinas
2. estabelece o tempo de estudo para cada uma
3. segue a sequência definida
4. ao terminar uma disciplina, passa para a próxima
5. ao finalizar o ciclo, ele reinicia

Diferente de cronogramas fixos, o ciclo permite maior flexibilidade quando a rotina muda.
