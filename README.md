# Onde Eu Parei

Aplicação web para gerenciamento de estudos baseada em ciclos, desenvolvida para auxiliar estudantes na organização da rotina de preparação para ENEM e concursos públicos.

O sistema permite criar ciclos de estudo personalizados, acompanhar progresso e retomar automaticamente o ponto onde o estudante parou.

---

## Sobre o Projeto

O **Onde Eu Parei** digitaliza o método de ciclos de estudo, amplamente utilizado por estudantes de concursos e ENEM.

O método consiste em organizar disciplinas em sequência contínua, permitindo maior flexibilidade e adaptação à rotina do estudante.

---

## Funcionalidades

- Criação de ciclos de estudo personalizados  
- Gerenciamento de disciplinas  
- Controle de progresso por ciclo  
- Registro de sessões de estudo
- Incluir anotações, to do e lista de questões em conteúdos
- Retomada automática do último ponto estudado  
- Visualização de métricas de desempenho  

---

## Método de Estudo

O sistema é baseado no **ciclo de estudos**, onde:

- As disciplinas são organizadas em sequência  
- O estudante avança continuamente no ciclo  
- Ao final, o ciclo reinicia  
- O progresso é contínuo e flexível  

---

## Interface

A interface foi projetada com foco em:

- Clareza visual  
- Navegação simples  
- Acompanhamento rápido do progresso  
- Organização das disciplinas e ciclos
